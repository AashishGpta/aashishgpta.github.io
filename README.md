# aashishgpta.github.io

Source for my personal website, live at **[aashishgpta.github.io](https://aashishgpta.github.io)**.

I'm Aashish Gupta, a VICO Postdoctoral Fellow in astronomy at the University of Virginia, working on how star-forming environments shape planet-forming disks. This website is a single-page profile covering my background, CV, and key research projects.

## Structure

| Path | Contents |
| --- | --- |
| `index.html` | The entire site: intro, about, research portfolio, contact |
| `css/`, `fonts/` | Styles and web fonts |
| `js/` | Interaction and animation scripts |
| `images/` | Profile photo and research figures (`images/portfolio/`) |
| `docs/` | CV and other downloadable documents |
| `styles.html` | Template style reference, not linked from the live site |

## Deployment

GitHub Pages builds from the `main` branch. Pushing to `main` publishes the site.
